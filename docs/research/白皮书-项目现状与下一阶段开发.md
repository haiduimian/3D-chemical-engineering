> 版本：R9 ｜ 生成依据：R0~R9 全迭代报告链（docs/research/）与工具链实测数据

## 1. 最终确认的架构（R9 当前代码结构）

- **渲染管线**（PlantScene.ts）：`RenderPass → SSAO(强机) → UnrealBloomPass(阈5.0) → GodRays体积光(强机) → 青橙分级(亮度保持) → Vignette → OutputPass(AgX)`；Composer RT 开 MSAA 4x；曝光由时段系统按预设托管（0.30 / 0.50 / 1.90）
- **时段系统**（timeOfDay.ts）：午后/黄昏/夜景三档预设（31 字段×3），0.8s easeInOut 全字段插值（太阳方向·Preetham·灯光色温强度·雾·曝光·后期·路灯·星层·IBL 强度）；过渡中点切换 IBL 内容（异步懒烘焙 + 空闲预热 + pendingEnv 兜底轮询）；阴影贴图按需刷新（过渡中点+终态 needsUpdate）；指定档位均值互差 ≤±8%（R9 实测 5.01%/4.51%/0.52%）
- **天空/IBL**（sky.ts）：SkyRig —— Preetham 三段式 HDR 因子（skyScale/sunBoost/skyClamp）uniform 化并登记入材质 uniforms；**IBL 烘焙使用天空克隆材质（R9 根因修复：烘焙永不改写可见天空的 uniforms）**；三档独立 PMREM RT 全量缓存；地面反弹随档位变色；星空 1200m 内球壳（fog:false，仅夜景可见）
- **光照体系**：灯组句柄化（主光 4096² 或按画质档 sun Int 3.8 / 月光 2.3 / 补光 / rim / 半球 / 路灯点光×3 0~320cd / 灯头自发光 0.25~9 随档插值）；**R9：`shadowMap.autoUpdate=false` + 构造/过渡时 needsUpdate（官方按需更新范式）**
- **材质体系**（pbr.ts/textures.ts）：MeshPhysicalMaterial（clearcoat/anisotropy/iridescence）+ 程序化贴图（512px 级）；**R9 金属度二值化：paintedSteel 0.06 / pipeMaterial 0.12 / pumpBody 0.12 / motorOrange 0.08（漆面非金属化，光泽交 clearcoat）**；全材质实例缓存共享
- **工艺拓扑**（plantLayout.ts/ports.ts/path.ts/pipes.ts）：端口注册表→L形折线→圆角弯头→Tube；分层高度 4.0/5.4/6.0/17/17.5/20；碰撞重叠 =1 处（泵出口法兰端到端语义对接）
- **画质分档**（R9）：weak/mid/strong（核数+设备内存双判定）：weak 关阴影/SSAO/Bloom/GodRays/浮尘 dpr1；mid 主影 2048² 无核心影 dpr≤1.5；strong 4096²+核心影 2048² dpr≤2
- **性能面板**（R9）：PlantScene 1s 节流采样 FPS/DrawCall/三角形/纹理 + 画质档；App.vue「性能面板」开关
- **设备建模**（plantShapes.ts/valves.ts）：程序化（封头/法兰/护栏/爬梯/护笼/平台/液位计/铭牌 512px/灯）；接触阴影盘 0.045m
- **环境**（environment.ts）：双层云、蒸汽、浮尘、火炬、城区远景+航空灯、厂界灌木带、电缆桥架、灭火器箱、地面标线/油渍/伸缩缝、道路路灯×7（3 真光）
- **交互/数据**：OrbitControls 接管、第一人称巡检、SOP、报警场景、数据柱/面板、MockDataSource；☀午后/🌇黄昏/🌙夜景 三档切换
- **工程防线**：`emissionInvariants.ts` 规则表 + 截帧工具运行时采样；timeod-check（时段专项：过渡平滑/三档互差/hiPct/真闪烁/天空带断言）；sky-preset-probe / sky-initial-probe（天空 uniforms 时间线诊断）
- **工具链**（scripts/）：capture-frames、pngdiff、probe-runtime、godrays-test、whitespot-locate、pipe-collision、trace-glint-scan、firecrawl-research、firecrawl-visual、timeod-check、sky-preset-probe、sky-initial-probe、sky-diagnose
- **验收服务器**：headless 验收统一走 `vite preview`（dev server 的 HMR 会污染无头页面）
- **依赖**：three@0.180（AgX/物理光照单位）、vue@3.5、vite@6、aurea-eden
- **部署**：main（源码）+ gh-pages（dist，base=/3D-chemical-engineering/）

## 2. 已废弃方案（勿重复踩坑）

（R0~R7 全部保留，追加 R9 条目：）
- **❌ IBL 烘焙直接改写共享天空材质的 uniforms**（预热烘焙把可见天空永久置成夜景档 → 页面 ~10s 后天空变黑）→ 烘焙一律使用天空克隆材质；共享材质只允许时段状态机写入

- **❌ 过渡帧计入闪烁热点**（天空移动误报数千）→ 稳态帧 tripline（明暗交替）
- **❌ headless 探针走 vite dev**（源码热更 → 页面中途重载 → 假异常）→ 统一 vite preview

## 3. 待解决痛点（性能/逻辑瓶颈）

- **性能**：真实 GPU 帧率已可从性能面板读取，但未做公开基准对比；主阴影按需更新已落地，
  云影投影（P1 遗留）未做；弱机内存档位（顶点简化/纹理降档）未做
- **交互**：近景无部件级拾取；第一人称无碰撞体（可穿设备）；OrbitControls 接管逻辑脆
- **布局工程化**：管线碰撞检测是事后验证；端口/路径无构建期自动避让与 CI 门槛
- **数据**：MockDataSource 无真实数据接入（WebSocket/OPC-UA 演示位空置）
- **氛围**：夜景无湿地面反射；无天气粒子（R8 大厂基准 §4 候选）
- **部署**：gh-pages 手动推送（无 Actions workflow）；使用过的 token 需轮换
