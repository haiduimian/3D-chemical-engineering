## 1. 最终确认的架构（R10 当前代码结构）

- **渲染管线**（PlantScene.ts）：`RenderPass → SSAO(强机) → UnrealBloomPass(阈5.0) → GodRays体积光(强机) → 青橙分级(亮度保持) → Vignette → OutputPass(AgX)`；Composer RT 开 MSAA 4x；曝光由时段系统按预设托管（0.30 / 0.50 / 1.90）
- **时段系统**（timeOfDay.ts）：午后/黄昏/夜景三档预设（32 字段×3，含 R10 云影强度），0.8s easeInOut 全字段插值（太阳方向·Preetham·灯光色温强度·雾·曝光·后期·路灯·星层·云影·IBL 强度）；过渡中点切换 IBL 内容（异步懒烘焙 + 空闲预热 + pendingEnv 兜底轮询）；阴影贴图按需刷新；指定档位均值互差 ≤±8%
- **天空/IBL**（sky.ts）：SkyRig —— Preetham 三段式 HDR 因子 uniform 化并登记入材质 uniforms；**IBL 烘焙使用天空克隆材质（R9 根因修复）**；三档独立 PMREM RT 全量缓存；星空 1200m 内球壳（仅夜景可见）
- **光照体系**：灯组句柄化（主光/月光/补光/rim/半球/路灯点光/灯头自发光随档插值）；`shadowMap.autoUpdate=false` + 构造/过渡时 needsUpdate（官方按需更新范式）
