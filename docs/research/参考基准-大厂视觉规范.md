## 1. 标杆产品怎么说（本轮抓取的原始素材）

### NVIDIA Omniverse（工业数字孪生渲染标杆）
- "Simulation-ready worlds"：渲染与物理/传感器同源，场景必须**物理一致**（PBR 材质、真实光单位）
- RTX 路径追踪级预演 vs 实时预览分离：**预演用实时光照近似、交付级用光追烘焙/降噪**——
  本项目 WebGL 对应关系：实时渲染（三档时段插值）+ 静态烘焙（IBL/阴影）
- 工业厂房数字孪生：激光扫描现实网格（reality mesh）+ 设计模型叠加、机器人/物料流动画验证

### Bentley iTwin（基础设施数字孪生平台）
- 可视化 = "把资产带活"：**传感器数据直接叠加在模型元素上**（IoT overlay）
- 装饰器/标记（decorators & markers）：高亮关键区域、工作流标注、外部文档上下文
- 进阶可视化：动画序列、粒子效果（雪/雨/车流）、**heat map（热力图）**、剖面裁切、多机位相机
- 结论方向：**数据驱动的视觉叠加 + 粒子氛围 + 热力图**是大厂孪生的标配第三层（模型→光照→数据层）

### AVEVA E3D Design（化工/能源工厂设计标杆）
- 数据为中心（data-centric）：3D 模型不是"图纸"而是**带物料规格/连接关系的数字资产**
- 激光扫描 reality mesh 与设计模型叠加验证："design never at odds with construction"
- 碰撞检查（clash detection）在设计期完成 —— 本项目 pipe-collision 工具同理念

## 2. 视觉规范提炼（跨来源汇总）

### 2.1 配色（Color Palette）
| 场景 | 大厂规律 | 落地建议（本项目） |
|---|---|---|
| 日间/午后 | 天空高亮蓝（#7FB2E5~#A8C8EC）、阳光暖白（#FFF0DC）、地面中灰（#6A6F75）；饱和度克制，暗部不脏 | ✅ 午后档已按此调（skyScale 0.55 / sun 0xFFF0DA） |
| 黄昏 | 天空从地平线暖橙（#E8A860）向天顶蓝灰（#4A6A80）渐变；主光色温 3000~3500K（#FFD2A0）；补光偏冷（#9DB2D8）压出冷暖对比 | ✅ 黄昏档继承 R7 光型，N1 提亮并去冷（fill #A9B8D6） |
| 夜景 | 天空深蓝（#0D1526），主光=月光冷白蓝（#9DB4E8），**路灯/窗灯暖橙（#FFB066）点缀 → 冷暖点状对比是夜景高级感来源** | ✅ 夜景档：路灯 110cd + 灯头 Ei 8 + 月光 0.9 |
| UI/大屏 | 暗色玻璃拟态（rgba(15,21,28,0.85) + blur）、主题高亮蓝 #185FA5、数据绿 #6FCF97、报警红 #E24B4A；同类色避免相邻，用对比色区分数据语义 | ✅ 已对齐（App.vue） |
| 大屏构图 | 图扑/Hightopo：按人眼视域（水平 90~120°）规划视觉中心、色彩主次的分布；**背景色占比 60%、主体 30%、强调色 10%** | ⚠️ N2 建议：设备高亮（拾取/报警）统一走 10% 强调色通道 |

### 2.2 材质（Material）
| 技术点 | 大厂做法 | 本项目对照 |
|---|---|---|
| PBR 纪律 | 金属只靠 metalness+envMap（无假高光贴图）、粗糙度随地况变化（污损/划痕"拥抱不完美"） | ✅ pbr.ts 程序化纹理 |
| 三层控制 | base color / roughness / normal 三贴图平衡；"trim metal（克制的金属高光）" —— stylized 流程也强调 spec 可控 | ✅ clearcoat/anisotropy 已用；⚠️ 夜景下金属反射依赖 IBL 强度 0.25，需验证不发黑 |
| 物理单位 | Omniverse 强调光强物理单位（lux/candela） | ✅ PointLight candela（decay=2）、DirectionalLight 按辐照度语义调 |

### 2.3 阴影（Shadow）
| 技术点 | 大厂做法 | 本项目对照 |
|---|---|---|
| 阴影分级 | 主阴影 + 近场高密度接触阴影（contact shadow）；远处建筑可无阴影（被雾吃掉） | ✅ PCFSoft + 4096² 主太阳 + 接触盘；核心区 2048² 影子光（R3） |
| 动态阴影 | three.js 官方：静态场景 `shadow.autoUpdate=false` + 太阳移动时 `shadow.needsUpdate=true`（只重渲染一次）| ⚠️ N2：时段切换瞬间触发一次阴影更新，全年均摊掉逐帧 shadow map 成本 |
| 月光阴影 | 夜景下月亮光也可产生长影（多一道叙事层） | ✅ 夜景主光=月光 0.9 |

### 2.4 光效（Lighting / Effects）
| 技术点 | 大厂做法 | 本项目对照 |
|---|---|---|
| 三点光 | 主光:补光:轮廓光 ≈ 10:1.5~2:2~3（比例随氛围调整；轮廓光常给到 0.7~1.0） | ✅ 黄昏 3.6 : 0.32 : 0.8；午后 3.9 : 0.34 : 0.5 |
| 光色联动 | UE5 Color Themes：**同一场景多套"光色主题"一键切换**——正是时段系统的别名；切换时所有光源/雾/后期联动而非单灯突变 | ✅ 本系统全字段插值 |
| 曝光 | ArtStation：先定曝光 → 再定天空 → 再放主光；夜景曝光 +20~30% 让暗部可读 | ✅ 曝光 1.05/1.12/1.35 |
| Bloom | 只作用于真光源；阈值越高光晕越"灯泡感" | ✅ HDR 阈值 5.0 + 发光不变量 |
| 体积光 | God Rays/丁达尔是氛围关键；夜景下不强求（路灯局部光晕即可） | ✅ godRaysStrength 0.2→0.05 夜景淡出 |

### 2.5 布局与交互样式（Layout & Style）
| 维度 | 大厂做法 | 本项目对照 |
|---|---|---|
| 孪生层叠 | 模型（真实感）→ 数据层（IoT/热力/报警叠加）→ 语义层（标记/注释/相机导览） | ✅ 数据柱/面板/危险区/巡检已具备；⚠️ N2 加标记/注释层（rope 引导） |

| 主题强调 | 高亮蓝 #185FA5 + 数据绿 #6FCF97 + 告警红 #E24B4A 三色系贯穿 | ✅ 已对齐 |

## 4. N2 视觉方向（下一轮候选，按基准推导）

1. **阴影按需更新**（官方范式）：时段切换时 `shadow.needsUpdate = true`，日常静态场景零阴影重算 → 中端 GPU 帧率红利
2. **夜景地面反光**：雨后/湿地面反射（大厂夜景标配）——反射探针或简化的粗糙反射平面，PPI 提升显著
3. **标记/注释层**：Bentley iTwin 的 decorators/markers → 设备铭牌类选择+注释气泡
4. **粒子天气**：Bentley 有 Snow/Rain 示例；本场景可加"夜景悬浮雾气粒子"或"晨曦薄雾"
5. **10% 强调色纪律**：报警/危险区/巡检点统一走 10% 强调色（当前红色通道已统一，需复核全局色卡）
