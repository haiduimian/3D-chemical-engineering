## R2 验证结果

### 体积光功能验证（strength 0 vs 0.6 开关对照，同机位）

| 指标 | 数值 |
|---|---|
| passes 顺序 | RenderPass → SSAO → Bloom → **GodRays** → 分级 → 晕影 → Output ✓ |
| 太阳屏幕坐标（默认机位） | uSunRaw=[2,2]（屏外，逆光）→ uSun=(0.78, 1.0)（钳到上缘）✓ |
| 开/关帧差异 | meanAbsDiff=0.66，**maxDiff=128.7**（强档下光柱明显）→ shader 管线运转正常 |
| 生产档 strength=0.2 | 均值差 ~0.22（subtle 暖光层，不抢主体） |

### 闪烁回归检查（20 帧 × ~10s，像素级）

| 指标 | R1 | R2 | 结论 |
|---|---|---|---|
| 全局帧均值 | 100.36 | 100.28 | 灌木剪影/vignette 微调，亮度稳定 |
| 全局时间方差 | 0.006 | 0.008 | 画面主体稳定（云/蒸汽漂移量级）|
| 热点像素 max std | 36.9 | 35.7 | 无回归；热点仍为信标光晕/云缘的平滑呼吸 |
| 热点像素计数(std>30) | 3 px | 6-10 px（散布在 526~812, 326~392） | 体积光未引入时间噪声（静态哈希 dither），热点依旧集中在原发光体区域 |

### 性能
- SwiftShader 软件渲染下 fps 0.8→0.6（新增 1 个 56 采样全屏 pass，实测开销 ~10-15%）；真实 GPU 上该 pass 开销≈0，灌木为 1 个 InstancedMesh DrawCall（160 例）。
- `vite build` 产物 1643→1646KB（+0.2%，shader 常量）。
