# 3D 化工厂（丙烯酸甲酯合成装置）需求方案与实施计划

> 技术选型：**Aurea EDEN**（基于 Three.js 的 3D 可视化框架，npm 包 `aurea-eden`）
> 目标：根据真实工艺流程与真实化工设备形态，建模并生成一个**完整、高清、逼真**的 3D 化工厂。
> 文档版本：v1.0（2026-09-01）

---

## 一、需求归纳总结

### 1.1 项目目标

| 维度 | 要求 |
|---|---|
| **完整性** | 覆盖"原料混合与反应 → 酸回收 → 醇回收 → 酯精制 → 产品储存 → 阻聚剂辅助管控"全流程，不缺任何一台关键设备 |
| **高清逼真** | 设备按真实化工设备形态建模（塔器、反应器、换热器、球罐、泵、管廊），PBR 材质 + 实时光影，达到"工业级效果图"观感 |
| **工艺正确性** | 3D 场景中的管线连接、物料流向、操作条件（温度/压力）必须与真实工艺流程一致，可作为工艺教学/展示用途 |
| **可交互** | 相机自由漫游、点击设备查看信息、ANALYZE 模式查看运行数据（Aurea EDEN 原生能力） |
| **技术栈** | Aurea EDEN + Three.js + Vue 3（用户熟悉 Vue3，EDEN 官方提供 Vue 组件封装） |

### 1.2 核心工艺需求（用户原始流程归纳）

本装置为**丙烯酸 + 甲醇酯化制丙烯酸甲酯（MA）**装置，五大功能区：

1. **原料混合与反应区**
   - 新鲜丙烯酸（红线）与过量循环甲醇（蓝线）混合 → 预热 → 进入固定床管式反应器
   - 催化剂：强酸性阳离子交换树脂
   - 主反应：丙烯酸 + 甲醇 ⇌ 丙烯酸甲酯 + 水（可逆放热酯化）
   - 操作条件：80–100 ℃、0.3–0.5 MPa（液相）
2. **第一步分离——酸回收**：反应产物 → 酸分离塔；未反应丙烯酸（高沸点）从**塔釜**分出，经循环管线打回反应器入口
3. **第二步分离——醇回收**：塔顶轻组分（MA + 水 + 甲醇）→ 甲醇回收塔；甲醇（低沸点）从**塔顶**分出，循环回反应器（维持过量甲醇，推动平衡右移）
4. **最终精制——酯提纯**：脱甲醇物料 → 酯精制塔（共沸/萃取精馏脱水脱重组分）；塔釜/侧线采出 **≥97%** 高纯产品 → 产品球罐
5. **辅助管控——阻聚**：对苯二酚（HQ）阻聚剂经计量泵**连续注入各精馏塔回流管线**，防止丙烯酸/酯类高温聚合堵塞设备

### 1.3 视觉与体验需求

- **管线颜色语义化**（用户明确要求红/蓝区分原料）：

| 管线 | 颜色 | 说明 |
|---|---|---|
| 丙烯酸（新鲜 + 酸循环） | **红色** | 高沸点酸性物料线 |
| 甲醇（新鲜 + 醇循环） | **蓝色** | 低沸点醇性物料线 |
| 反应产物/塔进料 | 橙黄色 | 反应器出口 → 酸分离塔 |
| 塔顶轻组分 | 银灰/白 | 各塔塔顶馏出线 |
| 成品 MA | 金黄/亮黄 | 酯精制塔 → 球罐 |
| 阻聚剂 | 紫色（细管） | HQ 溶解罐 → 各塔回流管线注入点 |
| 水路/蒸汽 | 绿色/灰白 | 公用工程（可选做） |

- **真实设备形态**：塔器要有塔体+裙座+平台+回流罐+再沸器；反应器为列管式固定床外形；球罐带支柱；泵为卧式离心泵+电机；管廊多层钢结构
- **动画**：管线内物料流动动画（流向可视化）、泵叶轮/搅拌旋转、ANALYZE 模式 value bar 数据跳动
- **氛围**：深色工业主题（EDEN DARK 主题契合），地面混凝土、设备金属漆、天空盒/环境光照

## 二、工艺流程与设备清单（建模依据）

### 2.1 工艺流程图（文字版 PFD）

```
丙烯酸储罐 V-101 ──红──┐
                        ├→ 混合器 M-101 → 预热器 E-101 → 固定床反应器 R-101
甲醇储罐 V-102 ──蓝──┘   （80~100℃, 0.3~0.5 MPa, 酸性阳离子树脂）        ↑
                                        │                    红线(酸循环) │
                                        ↓ 产物                          │
                                  酸分离塔 T-101 ←──────── 塔釜(丙烯酸) ─┘
                                        │ 塔顶(MA+水+甲醇)
                                        ↓
                                  甲醇回收塔 T-102 ──蓝(塔顶甲醇循环)──→ 回反应器入口
                                        │ 塔釜(脱甲醇物料)
                                        ↓
                                  酯精制塔 T-103 ──黄──→ 产品球罐 V-105 (MA ≥97%)

对苯二酚溶解罐 V-104 + 计量泵 P-105 ──紫(细管)──→ T-101/T-102/T-103 回流管线连续注入
```

## 三、技术实施方案

### 3.1 Aurea EDEN 能力评估与扩展策略

Aurea EDEN 定位是"3D 图表框架"，五层架构：`Diagram → Element → Shape / Connector / Material`。做 3D 化工厂的映射策略：

| EDEN 概念 | 化工厂映射 | 实现方式 |
|---|---|---|
| **Diagram（自定义 Notation）** | `ChemicalPlantDiagram` | 继承 `Diagram`，注册设备元素类型、管线连接器类型、化工主题 |
| **Element** | 每台设备（塔/罐/反应器/泵…） | `addEquipment('T-101', {...})` 链式 API |
| **Shape（自定义）** | 设备的 3D 几何 | 继承 `Shape`，用 Three.js `CylinderGeometry`/`SphereGeometry`/`LatheGeometry`/`ExtrudeGeometry` 程序化拼装设备；高精度件可包一层 GLTF 加载（Three.js `GLTFLoader`） |
| **Connector（自定义）** | 工艺管线（带颜色语义 + 流向动画） | 继承 Connector，支持折线 waypoints（沿管廊走线）、圆角弯头、管径粗细映射公称直径、自定义流动纹理动画 |
| **Material（自定义）** | PBR 材质库（不锈钢/碳钢漆/保温铝皮/混凝土/球罐银白） | 继承 Material 封装 `MeshStandardMaterial`（metalness/roughness），统一色调管理 |
| **ANALYZE 模式 value bars** | 运行数据可视化（温度/压力/流量/液位） | 每台设备挂 1–4 根 value bar，色标映射：温度红热-蓝冷、压力高压红 |
| **Badge** | 运行/报警状态角标 | 报警设备挂金色警示徽章 |
| **主题** | DARK 工业夜景主题 | EDEN 原生 LIGHT/DARK + 语义色覆盖 |
| **Vue 组件** | 嵌入 Vue3 页面 | `aurea-eden/vue` 官方封装，或直接用 Diagram API |

### 3.2 系统架构

```
┌─────────────────────────────────────────────────┐
│  Vue 3 应用层（UI 面板：设备信息卡 / 图例 / 模式切换） │
├─────────────────────────────────────────────────┤
│  ChemicalPlantDiagram（EDEN 自定义 Notation）      │
│  ├─ 设备元素层（EquipmentElement × 自定义 Shape）    │
│  ├─ 管线连接层（ProcessPipeConnector，红/蓝/黄…）    │
│  ├─ 环境层（地面/天空盒/灯光/阴影，Three.js 直挂）     │
│  └─ 数据层（模拟工况数据源 → value bars / badges）    │
├─────────────────────────────────────────────────┤
│  Three.js（PBR 渲染 / GLTFLoader / 后处理）         │
└─────────────────────────────────────────────────┘
```

### 3.3 逼真渲染方案（"高清逼真"的落地手段）

1. **PBR 材质**：全部设备用 `MeshStandardMaterial`，金属设备 metalness≈0.85/roughness≈0.35；漆面 metalness≈0.1/roughness≈0.6；保温层用拉丝铝皮质感
2. **光照**：半球光（天空环境）+ 平行光（太阳，投影 2048 阴影贴图）+ 塔区投光灯；可选 `RoomEnvironment`/HDRI 环境贴图增强金属反射
3. **动画**：
   - 管线流动：自定义 Connector 上叠加 `THREE.Line`/管道纹理 `map.offset` 滚动，速度 ∝ 流量
   - 泵：电机风扇旋转；球罐液位：半透明液面升降
4. **后处理**（可选增强）：SSAO 环境光遮蔽 + Bloom 泛光，需从 EDEN 拿到底层 renderer/scene 后挂 EffectComposer
5. **性能分级**：LOD（远景减面）、InstancedMesh 复用阀门法兰等重复件、像素比 clamp 2

### 3.4 场景总平面布置（Plant Layout）

按真实装置区划，坐标采用 EDEN `positionAt()` 手工精确定位（化工布置不适用自动布局）：

```
┌────────────────────────────────────────────────┐
│  北：罐区（V-101红、V-102蓝、V-105球罐、V-104）＋围堰 │
├────────────────────────────────────────────────┤
│  中：管廊（东西向贯穿，三层）                        │
├────────────────────────────────────────────────┤
│  南：反应区（M-101/E-101/R-101）→ 塔区（T-101/102/103 │
│      一字/品字排开，塔间联平台）＋ 泵棚（P-101~105）    │
└────────────────────────────────────────────────┘
```

物料走向总体自西向东：罐区 → 反应 → 分离 → 精制 → 球罐，与工艺流程方向一致，参观动线清晰。

### 阶段 1：工艺流程骨架（1 天）
- 定义 `ChemicalPlantDiagram`，先用简化几何（占位圆柱/立方体）把 2.1 节全部设备与管线连出来
- **验收点：红/蓝/黄管线连接关系与 PFD 完全一致**，VIEW 模式可总览

### 阶段 2：设备精细建模（2–3 天，工作量核心）
- 按 2.2 节清单逐台实现自定义 Shape，先塔器（三座塔复用同一 Shape 参数化：塔径/塔高/平台层数）
- 换热器/反应器/球罐/泵/储罐依次完成；管廊与钢结构平台
- **验收点：任意单台设备独立预览达到"一眼认得出是什么设备"**

### 阶段 3：场景逼真化（1–2 天）
- PBR 材质库统一上材质、灯光阴影、地坪/围堰/道路/绿化带、天空盒
- 管线流动动画、泵旋转动画
- **验收点：整体截图达到工业效果图水准**

### 阶段 4：数据与交互（1 天）
- 模拟工况数据接入 ANALYZE 模式 value bars（塔温、反应器压力、球罐液位、产品纯度 97%）
- 点击设备 → 信息卡（位号/名称/操作条件/材质）；图例面板；相机一键导览（罐区→反应→塔区→球罐，Tween 相机动画）
- 报警 badge 演示（如某塔温超 100℃）

### 阶段 5：优化与交付（0.5–1 天）
- 性能优化（LOD/InstancedMesh/像素比）、DARK/LIGHT 主题切换、打包部署

## 五、风险与对策

| 风险 | 说明 | 对策 |
|---|---|---|
| EDEN 本职是"图表"而非"场景渲染器" | 无内置天空盒/后处理等场景级能力 | 这些能力直接用 Three.js 在同一 scene 中挂载；EDEN 五层架构开放自定义，已在 3.1 验证可行 |
| 管线沿管廊走线复杂 | EDEN Connector 支持自定义 waypoints（N/S/E/W + 任意坐标），足够表达"下塔→沿管廊→上反应器"的折线 | 封装 `routePipe(from, to, {viaRack:true})` 辅助函数自动生成沿管廊的 waypoints |
| 逼真度上限 | 程序化建模细节有限 | 预留 GLTF 通道：高精度模型（如 SketchUp 3D Warehouse 化工厂件导出 glb）通过自定义 Shape + GLTFLoader 挂载 |
| 化工细节失真 | 塔的回流罐/再沸器、球罐支柱等容易遗漏 | 以 2.2 清单为验收 checklist，逐台对照 |
| 文字/标签在 3D 中可读性 | EDEN 支持 wrapped text，但距离远时模糊 | 设备标签用 CSS2DRenderer 挂 HTML 标牌（Three.js 生态方案） |

## 六、验收标准（Definition of Done）

1. ✅ **流程完整**：2.1 节 PFD 中所有设备与管线在 3D 场景中可找到并正确连接；酸循环（红）、醇循环（蓝）两条循环线闭合
2. ✅ **视觉逼真**：三塔 + 反应器 + 球罐 + 管廊主视角截图，非化工从业者也能认出"这是一个化工厂"
3. ✅ **数据可视**：ANALYZE 模式下关键设备显示温度/压力/流量 value bars，产品管线显示 ≥97% 纯度标识
4. ✅ **交互可用**：相机漫游、设备点击信息卡、模式切换（VIEW/ANALYZE）、一键导览
5. ✅ **性能达标**：中端笔记本（核显）稳定 ≥30 FPS
