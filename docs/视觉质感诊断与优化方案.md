## 2. 四维诊断：为什么"假"

### 2.1 材质与光照（核心）

**问题 A：环境贴图与题材错配**
`RoomEnvironment` 是"室内灯光棚"环境（亮窗+均匀顶光），用于**工业夜景**题材会让金属反射呈"棚拍感"，亮部过曝、暗部发闷。且所有材质 `envMapIntensity` 未分级（金属 0.85~1.3、漆面 0.5~0.6 已分但整体偏低），大面积漆面/保温缺少来自环境的漫反射能量 → 物体"干"。

**问题 B：表面无微起伏（无法线/凹凸信息）**
程序化纹理只有 `map`（颜色）和 `roughnessMap`，**没有 `bumpMap`/`normalMap`** → 保温铝皮波纹、漆面颗粒、拉丝全部是"画上去的假纹"，光照下没有起伏 → 塑料感。这是"假"的最大元凶之一。

**问题 C：自发光元件无泛光配合**
指示灯（emissiveIntensity 1.8）、管线脉冲、仪表盘大量自发光，但没有 bloom → 高光"干瘪"，一眼程序生成。

### 2.2 阴影

**问题 D：阴影贴图摊薄 + 偏移过大**
- 方向光阴影相机范围 **±100×±100**（场景仅 220×140），2048² 贴图摊到 ~0.2m/texel → 边缘糊、锯齿感
- `normalBias = 0.02` 偏大 → 阴影整体向光源方向"飘移"，设备与地面接触处出现**浮空感**
- 无接触阴影（Contact Shadow）→ 大设备脚下没有密实阴影，视觉悬浮

### 2.3 色彩与背景

**问题 E：纯色背景 → 无纵深层次**
单一 `0x1a2129` + 淡雾，天空与地平线无渐变 → 画面扁平、像"贴图"。夜场氛围需要**暗空渐变 + 冷暖对照**（地平线微暖光 vs 头顶冷蓝）。

**问题 F：色彩缺乏主导与分级**
主光暖白 + 补光冷蓝叠加后无主导色，设备色环/管线色孤立，无色调统一（Color Grading）。

### 2.4 后处理

**问题 G：零后期管线**
无 bloom / SSAO / DoF / 色彩分级。对比同类"高级感"场景（Three.js 官方 webgl_postprocessing、R3F 生态示例），后处理是质感分水岭：
- 无 bloom → 发光件干瘪
- 无 SSAO → 角落、设备间缝隙无接触暗影，空间感弱
- 无 DoF → 远近无虚化层次（工业大场景可选）

## 3. Drei 组件 → 原生 Three.js 等价映射

| Drei（R3F） | 原生 Three.js（本项目用） | 用途 |
|---|---|---|
| `<Environment preset>` | `PMREMGenerator + RoomEnvironment`（现有）→ 可换自建 Lightformer 环境 | 环境反射 |
| `<ContactShadows>` | 自建：设备底部 `ShadowMaterial` 圆盘（receiveShadow） | 接地阴影 |
| `<Lightformer>` | `MeshBasicMaterial` 矩形发光片 + 场景级 PMREM 烘焙 | 工业灯光棚环境 |
| `<Stars>/<Sparkles>` | `THREE.Points` 粒子 | 夜空/粉尘氛围 |
| `<Bloom>`（@react-three/postprocessing） | `EffectComposer + UnrealBloomPass + OutputPass` | 泛光 |
| 后处理 Color Grading | `OutputPass`（ACES）+ 可选 LUT 纹理 | 色调分级 |
| 景深 | `BokehPass`（three/examples，较重） | 景深（可选） |

## 4. 代码级优化方案（按性价比排序）

### S1 后处理管线：Bloom + SMAA + 输出分级 【最高性价比，强烈建议】
接管渲染循环（Diagram 自渲染用 `cancelAnimationFrame(diagram.animationFrameId)` 断链 + 覆盖 `animate=noop`），PlantScene.loop 改走 `composer.render()`：

```ts
import { EffectComposer } from 'three/examples/jsm/postprocessing/EffectComposer.js'
import { RenderPass } from 'three/examples/jsm/postprocessing/RenderPass.js'
import { UnrealBloomPass } from 'three/examples/jsm/postprocessing/UnrealBloomPass.js'
import { OutputPass } from 'three/examples/jsm/postprocessing/OutputPass.js'

// 断链 Diagram 自带渲染循环
cancelAnimationFrame(diagram.animationFrameId)
;(diagram as any).animate = () => {}

const composer = new EffectComposer(renderer)
composer.addPass(new RenderPass(scene, camera))
composer.addPass(new UnrealBloomPass(new THREE.Vector2(w, h), 0.55, 0.5, 0.8))
composer.addPass(new OutputPass())   // 应用 ACES tone mapping + sRGB
// 每帧：composer.render()；window resize：composer.setSize(w, h)
```
- `strength 0.55 / radius 0.5 / threshold 0.8`：只让自发光与高亮件泛光，普通材质不过曝
- **预期影响**：发光件柔光、画面立刻"电影感"（+1 档高级感）

### S2 阴影修正 【低成本】
```ts
sun.shadow.camera.left = -70; right = 70; top = 55; bottom = -45  // 贴合设备范围
sun.shadow.normalBias = 0.008                                      // 消除飘移
sun.shadow.bias = -0.0006
```
设备底部加接触阴影盘（每个设备 group 内）：
```ts
const shadowDisc = new THREE.Mesh(
  new THREE.CircleGeometry(radius * 1.7, 32),
  new THREE.ShadowMaterial({ opacity: 0.55 }),
)
shadowDisc.rotation.x = -Math.PI / 2
shadowDisc.position.y = 0.02
shadowDisc.receiveShadow = true
```
- **预期影响**：阴影清晰、设备"落地"不再悬浮（+0.5 档）

### S3 背景渐变 + 氛围 【低成本】
```ts
// 2x256 垂直渐变 CanvasTexture：顶部冷蓝黑 → 底部暖灰
scene.background = gradientTexture
scene.fog = new THREE.Fog(gradientBottom, 120, 320)  // 雾色与地平线一致
```
- **预期影响**：纵深层次、工业夜景氛围（+0.5 档）

### S4 材质 bump 细节 【低成本】
共享材质加 `bumpMap: map, bumpScale: 0.02`（用现有纹理复用为凹凸），保温/漆面/拉丝表面出现微起伏，破除塑料感。
- **预期影响**：材质真实度（+0.5 档）

### S5 环境反射分级（可选进阶）
用自建 **Lightformer 环境**（4~6 块矩形发光片绕场景放置，`PMREMGenerator.fromScene` 烘焙）替代 RoomEnvironment，光型可控：顶部冷光带 + 底部暖反射带 → 金属反射出现"上下冷暖"层次，更有工业感。

### S6 SSAO / DoF（可选，性能开销大）
`SSAOPass`（three/examples）增强接触暗影；`BokehPass` 做近景虚化。**建议 bloom + 阴影修正好后再评估**，低配机（≤4 核）默认关闭。

## 5. 实施顺序与验收

| 步骤 | 内容 | 预期影响 | 风险 |
|---|---|---|---|
| 1 | S1 后处理（bloom+输出分级） | 电影感 +1 档 | 中（需接管渲染循环） |
| 2 | S2 阴影修正 + 接触阴影 | 落地感 +0.5 | 低 |
| 3 | S3 背景渐变 + 雾衔接 | 氛围 +0.5 | 低 |
| 4 | S4 材质 bump | 材质真实度 +0.5 | 低 |
| 5 | S5 自建 Lightformer 环境 | 反射层次 +0.5 | 中（调光型耗时） |
| 6 | S6 SSAO/DoF | 空间感 +0.5 | 中高（性能） |

**验收标准**：① 指示灯/脉冲有柔和泛光不过曝；② 设备底部阴影密实无悬浮；③ 背景有暗空渐变、雾色衔接自然；④ 材质表面微起伏无塑料感；⑤ 弱机（≤4 核）自动关闭 bloom/SSAO 保帧率。

> 结论：**"假"的主因排序 = 无后处理（G）＞ 无表面微起伏（B）＞ 阴影飘移/无接触阴影（D）＞ 环境反射错配（A）＞ 纯色背景（E）**。先做 S1~S4 即可获得明显质感提升，S5/S6 按需进阶。
