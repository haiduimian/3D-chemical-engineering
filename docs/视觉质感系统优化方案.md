# 视觉质感系统优化方案（夕阳工业风）

> 版本：v1.0 ｜ 日期：2026-09-02 ｜ 项目：`D:\自己的小应用\3D化工厂`
> 技术栈：Vue3 + 原生 Three.js r180 + aurea-eden Diagram（渲染基座）
> 依据：联网调研 3D 写实渲染方法论（光照/大气透视/材质/色彩分级）+ 化工设备结构与配管标准 + 对现有代码的逐行体检
> 状态：**规划待评审**（本 repo 已具备 SSAO/Bloom/Bokeh、PBR、程序化建模等，本方案聚焦把质感拉到"工业级效果图"）

## 0. 目标定调：黄昏/落日工业感

**为什么选黄昏**：光线角度低 → 阴影长而暖、有方向性 → 立体感天然最强；暖橙侧光 + 冷蓝环境补光形成青橙冷暖对照，是写实渲染最高级的通用调性；也契合"化工装置傍晚灯火初上"的真实氛围。

视觉意象参考：
- 低角度暖落日（西侧暖橙主光，色温 ~3500K）
- 天顶到地平线冷蓝→暖橘的天空渐变
- 长而柔和的落日投影 + 设备脚下密实接触阴影
- 逆光侧设备勾出**暖色轮廓光(rim)**，拉开与背景的层次
- 远处设备被**大气雾**淡化（减饱和、偏冷），近处清晰锐利

> 注：该风格会**同时淘汰现有"白天晴空+蓝天绿地"的绿化观感**——黄昏下树木草地不再是青绿，而偏剪影/偏暖。需要在 `environment.ts` 全面重做光环境。

## 2. 优化方案（按五阶段实施）

实施原则：**先改光→再改材质→后改色彩→再补细节**；每阶段可独立验收、可回退；性能预算硬上限约和现状持平（弱机仍降级）。

### S0 光环境重做：落日定调（环境/背景/光照）
目标文件：`src/env/environment.ts`

1. **天空背景**：白天三色渐变 → 黄昏渐变（顶部冷蓝紫 `#3a4a6b` → 中部暖橙 `#d98a4e` → 地平线亮精细橙 `#f0b27a`），`scene.background = gradientTexture`。
2. **环境反射 Lightformer**：改为「西侧大暖橙主带 + 顶/东侧冷蓝天光 + 地平线暖反射带」，同步 `PMREMGenerator.fromScene` 烘焙，让金属反射呈现"上冷下暖"层次。
3. **主光**：太阳放大、角度压低（`position.set( -110, 45, 90 )`），色温暖 `0xffcf9a`，强度提高产生长影；阴影相机范围重设贴合落日投影方向，`mapSize` 维持 4096。
4. **补光**：天光冷蓝 `0x8498c4`；**新增反方向暖 outline/rim 光**（弱，仅勾边，`0xffb37a`）分离主体与背景。
5. **大气透视**：`Fog` 色改为暖灰 `0xe0b088`、near/far 前移到（160→420）并配 `FogExp2` 备选，让远景淡出。
6. **植被**：树冠改暖灰/偏橙剪影（黄昏逆光），去掉过亮青绿。

### S1 材质真实感（破除塑料感 + 拥抱不完美）
目标文件：`src/materials/pbr.ts` / `src/materials/textures.ts`

1. **加法线贴图**：为保温铝皮/漆面/拉丝钢/镀锌钢新增 `normalMap`，替换纯 bump，提升微起伏。
2. **污损贴花**：新增 `grimeTexture()`（深灰油渍点/划痕/氧化色斑）作为 `roughnessMap`/`aoMap` 叠加到保温、漆面、混凝土、罐壁，破除"刚出厂"感。
3. **roughness 由纹理驱动**：不再单一数值，让高光/反射有局部变化。
4. **地面增强**：混凝土加伸缩缝网格、油渍/沉砂色块、随机接缝；新增"地坪−路沿/排水沟"配套。
5. **玻璃件**：液位计玻璃、观察孔改用 `MeshPhysicalMaterial`（`transmission`+`roughness`）呈现真实透明反光（性能受限时降级回自发光）。
6. **环境反射分级补强**：漆面 `envMapIntensity` 0.72→0.9、保温 0.8→1.0，让黄昏暖环境光更多漫射进材质。

### S2 色彩体系统一（青橙分级，让语义色更突出）
目标文件：`src/scene/PlantScene.ts` / `src/materials/pbr.ts`

1. **后期调整**：`OutputPass`(ACES) 前串接颜色调整（可选 LUT/色温曲线），达"暗部偏冷青、高光偏暖橙"的统一基调；同步微调 Bloom threshold 以强化夕阳高光与仪表自发光。
2. **支撑件收敛**：泵壳蓝/电机橙/塔绿等**维持工艺识图**但适度下调饱和度并归入冷灰青/暖橙两条轴，避免与管线语义色抢眼；管廊/平台/护栏统一镀锌冷灰。
3. **语义色微调**：管线红/蓝/黄/橙/紫保持辨识度，但在黄昏暖光下会自然偏暖，需检查图例一致性与对比度（App.vue 图例）。

### S3 光影与立体感（轮廓光 + 长影 + 体积氛围）
目标文件：`src/env/environment.ts` / `src/scene/PlantScene.ts`

1. **落日长投影**：按新太阳角度重设 `sun.shadow.camera` 范围并加大 `normalBias` 修正，保证塔/反应器/球罐投影密实、无浮空。
2. **接触阴影增强**：ShadowMaterial 圆盘 opacity 0.5→0.65、半径随设备放大，贴合黄昏氛围（plantShapes.ts）。
3. **轮廓光(rim)**：主光反向加一道暖弱光只照亮设备逆光侧，必要时用 `RectAreaLight`/聚光辅助，分隔主体与背景。
4. **体积光/丁达尔（可选，性能分级）**：用 `FogExp2` + 少量尘埃粒子承接夕阳光柱；低配机（≤4 核）自动关闭，仅保留雾。
5. **SSAO 调参**：落日下加大 `kernelRadius`/强度，强化设备缝隙与管线交汇处暗影。

### S4 场景细节丰富（"廉价感"解药，性价比最高之一）
目标文件：`src/env/environment.ts`（新增函数）+ `src/layout/plantLayout.ts`（坐标）

1. **地面做实**：路沿石、排水明沟、道路双黄/边线标线、地坪伸缩缝与分隔。
2. **管线配套（工艺真实）**：为高风险/长管线（酸循环、甲醇循环、反应产物）叠加**蒸汽伴热细管**与保温端头；管线支架加密、静电接地线（细亮线自设备接地下）；就地压力/温度计（pipes.ts 的 `addPipeSupports` 扩展）。
3. **罐区安全设施**：围堰内加泡沫枪/灭火器、罐壁喷淋环管、静电接地桩、防火堤警示标牌。
4. **塔区配套**：安全阀顶部放空火炬头/阻火器、塔顶吊车梁、护栏巡检灯（夜间泛光点）。
5. **界区**：围墙/大门/厂界警示牌与灯柱（呼应"定位"理念）。
6. 复用之：`structuralSteel()`/`machinedSteel()`/`paintedSteel()`，不新增材质种类，控制 DrawCall 用量。

### S5 性能与交付（贯穿）
1. 新增细节件尽量走既有材质缓存与 `InstancedMesh`，避免 DrawCall 暴涨。
2. 弱机（`hardwareConcurrency<=4`）自动关闭体积光/SSAO/雾增强，维持现状帧率。
3. 打包前 `vite build` + `npm run preview` 验证首屏与帧率。

## 3. 实施顺序与验收

| 阶段 | 内容 | 验收点 | 风险 |
|---|---|---|---|
| S0 | 光环境落日重做 | 天空橙蓝渐变、长影、轮廓光初见、氛围立变 | 中（调光型耗试错） |
| S1 | 材质真实感 | 表面微起伏、有脏旧、地面不空旷、玻璃真实 | 低 |
| S2 | 色彩体系统一 | 画面整体偏青橙、语义色仍可辨识、曝光适中 | 低 |
| S4 | 场景细节丰富 | "像一个能跑的真化工厂"，管线伴热/安全设施/界区齐 | 低-中（DrawCall） |
| S3 | 光影深化（长影/rim/体积光选做） | 立体感再上一档 | 中 |
| S5 | 性能验收 | 中端≥50fps，弱机≥30fps 且交互可用 | — |

**总体验收**：默认视角截图达到"落日下的工业级化工厂效果图"；任意设备/管线/安全设施在近景下细节合理、无穿帮；帧率稳定、弱机自动降级。

## 4. 参考（调研来源，便于复核）

- 写实渲染三大基石：光/材质/细节；"拥抱不完美"（划痕/污渍/脏旧）+ 统一纹素密度
- 大气透视：远景减饱和、偏冷、降对比、边缘模糊（用于雾与纵深）
- 光型法：主光+补光+轮廓光(rim)+环境光(HDRI)+Gobo；软硬光结合
- 后期：色彩分级(青橙)、景深、泛光、体积雾
- 化工结构/标准：塔器（裙座/塔盘/内件/吊柱/人孔）、容器（封头/支座/安全阀/人孔/接管）、配管（HG/T 20519、保温/伴热/夹套、支架/静电接地）、罐区（围堰/防火堤/泡沫/喷淋）

> 本方案为**计划文档**，待确认后逐项落码。实现时各 Three.js API（`EffectComposer`/`SSAOPass`/`UnrealBloomPass`/`OutputPass`/`PMREMGenerator`/`MeshPhysicalMaterial` 等）将按 r180 官方与实例文档核对再接入（对应"开发时用 ctx7 查最新文档"）。
