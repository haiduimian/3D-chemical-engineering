# 02 验证工具与验收标准（命令集 + 通过判据 + 失败排查）

> 全部 headless 验收基于 Edge + SwiftShader 软件渲染（真实帧率无代表性，约 1~2 fps 属正常）。
> 统一 URL 基准：`http://localhost:4173/3D-chemical-engineering/`（vite preview，无 HMR）。

## 0. 环境准备与清理

```powershell
# 清理僵尸 headless Edge（数百秒 CPU 的老进程会拖慢 3~5 倍）——保留最近 60min 内的即可
Get-Process -Name msedge -ErrorAction SilentlyContinue |
  Where-Object { $_.StartTime -lt (Get-Date).AddMinutes(-60) } | ForEach-Object { Stop-Process -Id $_.Id -Force }

# 端口归属检查（5180=vite dev，4173=vite preview）
Get-NetTCPConnection -LocalPort 5180,4173 -State Listen -ErrorAction SilentlyContinue |
  Select-Object LocalPort, OwningProcess
# preview 启动（必须 --strictPort；build 后如页面引用旧哈希需重启该任务）
npm run preview -- --port 4173 --strictPort
```

## 1. 构建

```powershell
npm run build   # 通过标准：exit 0、无 TS/打包错误；记录 dist/assets 新哈希（如 index-XXXX.js）
```
**用于部署/验收的哈希一致性检查**：`(Invoke-WebRequest http://localhost:4173/3D-chemical-engineering/).Content`
须包含最新 dist 哈希；否则重启 preview。

## 2. 快速探针（调参回路，~4 min/轮）

```powershell
node scripts/sky-preset-probe.mjs --url http://localhost:4173/3D-chemical-engineering/
```
输出（每档一行）：`skyDebug`（uniforms 实况）+ `sky RGB`（天空直接采样）+ `fullMean/hiPct`。
**通过判据**：
- 三档 `fullMean` 两两互差 ≤±8%（白皮书契约；目标带 ~55~62 取决于历史档案）；
- `hiPct=0`；`pageErrors=0`；
- `envActive` 与当前档位一致；`skyParent:"skyGroup"`。
**失败排查**：
- uniforms 与档位不符 / envActive 停滞 → sky bake 或 pendingEnv 逻辑回归（见 R9 教训）；
- mean 漂移 >5% → 用 `node scripts/sky-diagnose.mjs <png>` 看 顶部(天空)/中部/下部 三带定位是哪层变了。

## 3. 天空时间线（动过 sky/烘焙必跑，~2 min）

```powershell
node scripts/sky-initial-probe.mjs --url http://localhost:4173/3D-chemical-engineering/
```
输出 t=0/1.5/5/11/20/35s 六点的 skyDebug + 截图。
**通过判据**：uniforms 全时间线保持当前档位（不得被预热烘焙改写）；
`skyParent:"skyGroup"`、`envSceneHasSky:false`、errs=0；t0 与 t35s 天空带亮度一致（sky-diagnose）。

## 4. 时段全量认证（**每轮必跑**，≈25~35 min）

```powershell
node scripts/timeod-check.mjs --url http://localhost:4173/3D-chemical-engineering/ --out .shots/timeod-r<N>
```
**通过判据（ALL TIME-OF-DAY CHECKS PASS，exit 0）**：
| 断言 | 契约 | R10 实测参考 |
|---|---|---|
| 过渡复位 | ≤2.5s（SwiftShader 采样补偿） | ~1.2~1.4s |
| 相邻帧全局均值差 | ≤±3% | max 0.83% |
| 三档均值互差 | ≤±8% | 4.85% / 3.85% / 1.04% |
| hiPct（三档） | ≤0.05% | 0% |
| 真闪烁（明暗交替 tripline） | ≤10px | 0 / 0 / 2 |
| 天空带（明档 >25 且 ≥ 夜景） | 天空随档位可辨识 | 70.7 / 90.5 / 68 |
| 静态+运行时发光不变量 | PASS | PASS |
**失败排查**：
- 某档均值偏差 → 该档 preset 曝光/天空/光强（探针调参循环）；
- flash>10 → 找闪烁源（emissionInvariants 规则表是否同步；灯具是否共享材质）；
- 天空断言失败 → 先跑 §3 区分"天空缺失"还是"断言阈值问题"。

## 5. 截帧回归（invariants + runtime + 像素热点 + sizeAudit，≈5~10 min)

```powershell
node scripts/capture-frames.mjs --url http://localhost:4173/3D-chemical-engineering/ --out .shots/frames-r<N> --frames 10 --interval 400 --clean --fast
```
**通过判据**：
- `invariants: PASS`；`runtime emission sampling` 全部 `OK(单侧)`；
- 帧均值稳定（帧间漂移 <±3%）、hiPct=0；
- 时间方差热点 blocks 仅出现在天空带（by=0，太阳光晕/火炬呼吸=设计内），场景中部/底部无闪烁块；
- 快照 `scene-snapshot.json` 中 `sizeAudit: []`（空数组=口径审计通过）。
**失败排查**：中部/底部热点 → whitespot-locate 定位发光体 + 对照 emissionInvariants 表。

## 6. 几何回归（每轮必跑，≈2~4 min）

```powershell
node scripts/pipe-collision.mjs
```
**通过判据**：`无重叠`（或仅列出"语义正确"项且相对上轮 **0 新增**）。
失败 → 端口/路径分层调整（R7 分了层体系：4.0/5.4/6.0/17/17.5/20），改后跑通再继续。

## 7. 巡检碰撞专项（动过布置/碰撞表必跑，≈2~4 min）

```powershell
node scripts/patrol-collide-check.mjs --url http://localhost:4173/3D-chemical-engineering/
```
**通过判据**：`ALL PATROL-COLLIDE CHECKS PASS`（碰撞体 ≥50、V-101 拒穿、管廊柱滑移、
空旷区自由、围堰阻挡+门洞）。失败 → 检查 `buildPatrolColliders()` 与布置数据一致性。

## 8. 像素级辅助（定位用）

```powershell
node scripts/sky-diagnose.mjs a.png b.png ...   # 输出 顶部0-45%/中部45-70%/下部70-100% 均值和 warmth(R-B)
```
- 天空修复前特征：顶部均值随曝光缩放、warmth 与中部相反；修复后：顶部带应有天空色相。
