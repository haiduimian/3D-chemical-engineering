## B. 白皮书模板（`docs/research/白皮书-项目现状与下一阶段开发.md` 升版规则）


## C. Nx 方案条目规范（写进白皮书 §4 的每条必须满足）

1. **P 级别**：P0=用户可见缺陷/重点指令；P1=体验/性能显著项；P2=功能增强；P3=远期。
2. **做法一句话**（引用大厂基准/官方范式出处更佳）。
3. **量化指标**：必须可被现有工具或新写专项工具执行（如"互差 ≤±8%"、"flash≤10"、
   "命中率 ≥90%（新增拾取专项脚本）"）。指标写"工具名 + 数值"，AI 才可验收。
4. **联动防线**：若影响端口/布置/发光体/材质，标注需同步的防线编号。

## D. 调研基准文档模板（`docs/research/参考基准-<主题>.md`）

```markdown
# 参考基准：<主题>
> 工具：firecrawl-visual / context7 / web_search ｜ 日期 ｜ 原始数据 <文件>
## 1. 标杆产品说法（来源 + 引用）
## 2. 视觉/技术规范提炼（表：维度 | 大厂做法 | 本项目现状 | 落地建议）
## 3. 对本项目 N<N+1> 的可落地项（每项：出处 + 改哪个文件）
## 4. 来源链接
```

## E. Commit / 分支规范

- commit 信息：`feat(3d): R<N> <一句话主题>`（如 `feat(3d): R10 管线口径体系/管廊完善/云影投影/巡检碰撞`）
- 一个迭代一个 commit；修正用 `--amend`；分支：main（源码）+ gh-pages（dist），无中间分支。
