# 03 工程防线与审查清单（代码纪律 + 禁止事项 + 四道防线）

## 1. 文件操作纪律（事故高发区）

| 规则 | 缘由 |
|---|---|
| 源码用 write/edit 工具，**禁止 pwsh 读写源码文件** | pwsh 按 ANSI 读写 UTF-8 → 中文注释整段乱码（R10 事故；恢复：`git checkout -- <file>`） |
| 新增引用必须同步 import | 引用未 import 成员 → 构造期 ReferenceError → 场景"半成品"且无显式报错（R10 事故） |
| 调试钩子（_tmp-*.mjs / _dbg-*）用完即删，不入库 | 仓库卫生 |
| 生成物/中间物（dist-bak-*、*raw.json 调研原文按需）不进版本库 | `.gitignore`: node_modules/dist/dist-bak-*/ .shots/.deploy-gh-pages/*.log |

## 2. 实现禁忌表（全部为已验证事故，见 06 决策记录）

- ❌ 烘焙/预览路径**直接改写共享材质 uniforms** → 必须用材质克隆；共享材质只允许"视觉状态机"写入
- ❌ GLSL 声明 uniform 但不登记 `material.uniforms`（GL 默认 0 → 黑天）→ 声明与登记同一处
- ❌ 主线程同步做重活（PMREM 烘焙等）→ 异步调度 + 状态兜底轮询
- ❌ 动态发光体强度穿越 Bloom 阈值 5.0（高频横跳 = 闪烁）→ 单侧于阈值或平滑斜坡
- ❌ 共享灯珠/灯头材质被多设备共用改写 → 按设备/阀门克隆
- ❌ 立即删除切换前仍在缓存/引用的 GPU 资源（贴图/纹理）→ 全量缓存，整体 dispose
- ❌ 过渡帧/动画帧计入"闪烁热点"统计 → 仅稳态帧；真闪烁用"明暗交替"tripline
- ❌ headless 探针走 vite dev（HMR 全量重载污染）→ 统一 vite preview
- ❌ 把"工艺有意变径"当作口径违规（泵出口三通支管）→ 审计白名单 + 工艺注释
- ❌ pwsh 改写 UTF-8 源码（见上表）
- ❌ 忘记给新增管线直径配端口口径（细于设备管嘴）→ autoDiameter 推导 + sizeAudit

## 3. 四道工程防线（每轮必查，改动必同步）

**防线 1：发光不变量（emissionInvariants.ts）**
规则表：每个动态/静态发光体强度范围，必须 `max<thr || min>thr`（thr=BLOOM_THRESHOLD 5.0）
或 `rampAllowed`（平滑斜坡）。⭐ 新增/修改任何发光体（灯、信标、火焰、路灯头、数据柱…）
必须先改此表再改代码；capture-frames 静态 + 8s 运行时采样双重校验。

**防线 2：口径审计（ports.auditPipePortSizes → PlantScene.sizeAudit）**
管线显式直径与端口推导(较大值) 偏差 >0.03m 即违规（console.error + 快照读取）。
白名单仅限"三通分配变径"等**工艺有意**场景（注释必须写工艺语义）。
⭐ 改任何端口 diameter 或管线 diameter 后检查白名单是否需要增删。

**防线 3：巡检碰撞表（firstPerson.buildPatrolColliders）**
59 个 AABB = 15 设备（按型体半径+平台余量）+ 围堰墙段（留 4m 门洞）+ 管廊柱/墩。
⭐ 改 EQUIPMENTS / 围堰布置 / 管廊坐标时必须同步此表；patrol-collide-check 自动化断言。

**防线 4：几何碰撞（pipe-collision + 分层高度体系）**
端口注册表 → L 形折线 → 圆角弯头；分层 4.0/5.4/6.0/17/17.5/20。
⭐ 新增管线/端口必跑 pipe-collision（0 新增）；同类管线同层交叉 → 抬/降 to 另一高度层。

## 4. 代码审查 Checklist（提交前逐项过）

- [ ] `npm run build` 通过
- [ ] 新发光体 → 防线 1 同步；新口径 → 防线 2 覆盖；新布置 → 防线 3 同步
- [ ] 新动画/呼吸频率低频（≤1.5 rad/s）且不穿越阈值
- [ ] 新材质复用缓存（`mat(key, params)` 模式），禁止每帧新建
- [ ] 新 InstancedMesh 聚合同类小件（管廊托架/柱/灌木带模式，控制 DrawCall）
- [ ] 新参数进 timeOfDay 预设（统一插值/升降级），不散落硬编码
- [ ] 弱机（weak）路径有降级开关（阴影/SSAO/GodRays/浮尘/云影）
- [ ] dispose() 覆盖新增资源与监听
- [ ] 无调试残留（console.log 乱打、_tmp 脚本、死代码）
- [ ] git staged 清单仅含本轮确认文件（见 00-README §4）

## 5. 性能预算（SwiftShader 只是回归用途；真实 GPU 以性能面板 FPS 为准）

- 全场景 DrawCall 目标：强机 <800（renderer.info.render.calls，性能面板可看）；
- 新增批量小件一律 InstancedMesh；点光总数保持 ≤5（路灯仅 3 真光）；
- 星空/浮尘/粒子密度按 weak 档降级。
